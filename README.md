# Placement Test — интерактивная веб-версия

Входной (диагностический) тест по английскому языку для 10 класса, уровень **B2/B2+**.
Один файл `index.html` + аудиофайл. Никаких библиотек, сборки, CDN и внешних шрифтов.
Работает офлайн — интернет нужен только в момент отправки результата в Google Форму.

---

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | весь тест: разметка, стили и логика в одном файле |
| `listening.mp3` | запись к разделу Listening (4 мин 03 с, пять отрывков) |
| `README.md` | этот файл |

Состав теста — 9 заданий, **70 оцениваемых баллов**:

| № | Раздел | Формат | Баллы |
|---|---|---|---|
| 1 | Listening | MCQ A/B/C, пять отрывков | 7 |
| 2 | Reading | подстановка фраз в пропуски A–F | 6 |
| 3 | Reading | MCQ A–D по тексту | 7 |
| 4 | Use of English | словообразование | 10 |
| 5 | Use of English | лексический тест с выбором | 10 |
| 6 | Use of English | формы глагола | 10 |
| 7 | Use of English | смешанные грамматические формы | 10 |
| 8 | Use of English | key word transformations | 10 |
| 9 | Writing | абзац 100–150 слов | не оценивается |

Уровневый состав: B1+ 2 · B2 36 · B2+ 26 · C1 6. Доля C1 — 8,6 %.

## Публикация на GitHub Pages

1. Создать репозиторий **`english-entry-test`** (Public — GitHub Pages для приватных репозиториев требует платного тарифа).
2. Загрузить в **корень ветки `main`** три файла: `index.html`, `listening.mp3`, `README.md`.
   Имя аудиофайла должно быть ровно `listening.mp3` — этот путь прописан в коде.
3. **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   ветка `main`, папка `/ (root)`, **Save**.
4. Через 1–2 минуты тест открывается по адресу:

   ```
   https://<ваш-логин>.github.io/english-entry-test/
   ```

5. Первый прогон сделайте **с телефона** и проверьте, что ответ появился в таблице формы.

### Предупреждение о доступности исходного кода

GitHub Pages отдаёт `index.html` любому, кто знает ссылку, и **исходный код страницы читается
целиком**, включая логику проверки. Ключ в файле хранится зашифрованным (XOR + base64), поэтому
в «Просмотре кода страницы» ответов не видно. **Это обфускация, а не защита:** ученик, который
откроет консоль браузера и вызовет функцию `ref()`, увидит весь ключ. Настоящая защита требует
сервера, проверяющего ответы на своей стороне.

Что это значит на практике: против «посмотрю исходник» механизм работает, против
целенаправленного обхода — нет. Поэтому тест стоит проводить в классе, под наблюдением.

## Настройка Google Формы

### Поля, которые должны быть в форме

Девять вопросов. Тип указан обязательно — поля 7–9 должны быть **«Текст (абзац)»**,
иначе многострочный отчёт и сочинение обрежутся.

| № | Вопрос | Тип | Пример значения |
|---|---|---|---|
| 1 | Имя | Текст (строка) | `Мария` |
| 2 | Фамилия | Текст (строка) | `Иванова` |
| 3 | Группа | Текст (строка) | `10-Б` |
| 4 | Баллы | Текст (строка) | `52 / 70 (74%) — оценка 4` |
| 5 | Уровень | Текст (строка) | `B2  [лестница C1 · полоса solid B2 74%]  B1+ 2/2 · B2 25/36 · B2+ 19/26 · C1 6/6` |
| 6 | Время | Текст (строка) | `НАЧАЛО 26.09.2026, 10:05 · СДАНО 11:19 · ВРЕМЯ 74 мин из 85 · уходов со вкладки: 3` |
| 7 | По заданиям | **Текст (абзац)** | `ПО ЗАДАНИЯМ: №1: 5/7 · №2: 6/6 …` |
| 8 | Ошибки | **Текст (абзац)** | построчный разбор: пункт, ответ ученика, верный ответ |
| 9 | Writing | **Текст (абзац)** | тема, число слов и полный текст сочинения |

|---|---|---|
| Имя | `entry.87069478` | `firstName` |
| Фамилия | `entry.327805807` | `surname` |
| Группа | `entry.29988280` | `group` |
| Баллы | `entry.1304620170` | `score` |
| Уровень | `entry.1905183439` | `level` |
| Ошибки | `entry.580301486` | `errors` |
| Время | `entry.1700793576` | `time` |

| Сочинение | `entry.1071151568` | `writing` |

### Настройки формы

- Все девять вопросов — **необязательные** (`Required` выключен). Обязательное поле ломает
  фоновую отправку.
- **Выключить** «Собирать адреса электронной почты» и «Ограничить до 1 ответа» — они требуют
  входа в Google-аккаунт, и отправка перестанет проходить.

### Как заменить форму на свою

Всё правится в блоке `CONFIG` в начале тега `<script>` в `index.html`.

1. Открыть форму → ⋮ → **«Получить предзаполненную ссылку»**.
2. Вписать в каждое поле слово `тест`, нажать **«Получить ссылку»**, скопировать адрес.
3. В адресе видны пары `entry.123456789=тест`. Перенести номера в `CONFIG.ENTRY`:

   ```js
   ENTRY: {
     firstName: 'entry.87069478',
     surname:   'entry.327805807',
     group:     'entry.29988280',
     score:     'entry.1304620170',
     level:     'entry.1905183439',
     errors:    'entry.580301486',
     time:      'entry.1700793576',
     byTask:    'entry.1327990814',
     writing:   'entry.1071151568'
   }
   ```

4. `FORM_ID` — длинный код из адреса формы между `/forms/d/e/` и `/viewform`.

В поставленном файле все девять ID уже прописаны — менять их нужно только при переходе на
другую форму. Поле, в котором остался незаменённый плейсхолдер, просто **не отправляется**,
а в консоли появляется предупреждение с его именем; остальные поля уходят как обычно.

Смена типа вопроса в форме **не меняет** его `entry.`-номер.

## Как это работает для ученика

**Титульный экран** — имя, фамилия, группа (все три обязательны) и четыре правила.
Ниже — строка о том, что имя, группа и результат уходят учителю и используются только
для оценивания.

**Тест** — девять экранов, по одному заданию на экран. Внутри задания все пункты видны сразу
и ответы можно править сколько угодно; после кнопки «Next task» вернуться к сданному заданию
нельзя, о чём предупреждает диалог.

**Аудирование** — запись можно запустить **дважды**. Попытка засчитывается только когда трек
доиграл до конца (событие `ended`): если вкладка закрылась на середине, попытка не сгорает.
Пауза и перемотка заблокированы на уровне событий `pause` и `seeking`. Когда попытки
исчерпаны, кнопка блокируется и появляется плашка.

**Таймер** — 85 минут, отсчёт ведётся от сохранённого момента старта, поэтому перезагрузка
страницы его не обнуляет. За 5 минут до конца — предупреждение. По истечении времени работа
отправляется автоматически, и в отчёт добавляется пометка «(автоотправка по таймеру)».

**Финал** — ученик видит только «Thank you. Your work has been submitted.»
Балл, оценка и уровень считаются, но **не показываются** — их видит только учитель в таблице формы.

## Как читать результаты

### Оценка

Считается от 70 баллов по заданиям 1–8. Writing в балл не входит.

| Процент | Баллы из 70 | Оценка |
|---|---|---|
| 81–100 % | 57–70 | **5** |
| 61–80 % | 43–56 | **4** |
| 41–60 % | 29–42 | **3** |
| 0–40 % | 0–28 | **2** |

### Уровень

В поле «Уровень» три числа подряд, и читать их надо вместе:

```
B2  [лестница C1 · полоса solid B2 74%]  B1+ 2/2 · B2 25/36 · B2+ 19/26 · C1 6/6
 ↑         ↑                 ↑                        ↑
итог   по ярусам        по проценту          сколько взято на каждом ярусе
```

- **Лестница** — самый высокий ярус, на котором взято не меньше 60 % пунктов, при условии что
  все ярусы ниже тоже взяты. Ярус B1+ — всего два пункта, отдельный порог по нему
  статистически бессмыслен (одна ошибка = 50 %), поэтому в расчёте он объединён с B2,
  а в строке показывается отдельно.
- **Полоса** — обычная шкала по общему проценту: ≤40 % B1/B1+ · 41–60 % B2 approaching ·
  61–80 % solid B2 · 81–92 % B2+ · 93–100 % C1.
- **Итог** — нижний из двух. Каждое измерение по отдельности врёт: лестница может выдать C1
  при 74 % общего балла, если шесть пунктов яруса C1 случайно взяты целиком; полоса не
  смотрит, какие именно пункты взяты. Совпадение двух — единственный защитимый вердикт.

**Расхождение между лестницей и полосой само по себе информативно.** Лестница выше полосы —
ученик берёт сложное, но сыплется на массовом материале: невнимательность, а не пробел в знаниях.
Полоса выше лестницы — прочная база, но потолок ниже заявленного.

### Разбивка по заданиям

Поле «По заданиям» даёт две строки: по каждому из восьми заданий и по трём разделам.
Читать так:

| Что проседает | О чём говорит | Куда смотреть |
|---|---|---|
| Task 1 (Listening) | восприятие на слух, особенно вывод и отношение говорящего | пункты 6 и 7 — они на импликацию, а не на факт |
| Task 2 | связность текста: кореференция, коннекторы, синтаксис придаточных | разбор по типу пропуска |
| Task 3 | чтение на вывод, а не на поиск фактов | пункт 7 — обобщение авторской позиции |
| Task 4 | словообразование, особенно отрицательные приставки | пункты 6, 7, 9 |
| Task 5 | коллокации, фразовые глаголы, идиомы | пункт 6 — идиома уровня C1 |
| Task 6 | система времён, перфектно-длительные формы | пункты 6–10 |
| Task 7 | условные, пассив, модальные перфекты, причастные обороты | пункты 4, 6, 8, 10 |
| Task 8 | перефразирование — самый чувствительный показатель активного владения | инверсия (3), каузатив (4), модальная дедукция (7) |

Устойчивый провал **только в Use of English** при нормальных Listening и Reading означает
рецептивное владение выше продуктивного: ученик понимает, но не порождает. Обратная картина
(Use of English в порядке, Listening проседает) — почти всегда дефицит аудирования, а не грамматики.

### Writing

В балл не входит, оценивается вручную по дескрипторам B2/B2+: выполнение задачи, диапазон и
точность грамматики и лексики, связность и организация. В поле приходит выбранная тема,
число слов и полный текст.

## Служебное

**Сброс для учителя.** Тест блокирует повторное прохождение: ключ `pta26_done` в localStorage
браузера ученика. Чтобы сбросить блокировку и прогресс — открыть адрес с `?teacher=reset`:

```
https://<ваш-логин>.github.io/english-entry-test/?teacher=reset
```

Адрес после сброса очищается сам. Нужно для собственных прогонов и для законной пересдачи.

Блокировка привязана к браузеру и устройству: другой браузер, режим инкогнито, очистка данных
сайта или второй телефон её снимают. Против «пройду ещё раз получше» работает, против
целенаправленного обхода — нет.

**Анти-чит.** Варианты в заданиях 1, 3 и 5 перемешиваются у каждого ученика свои, поэтому в
отчёте ошибки называются текстом варианта, а не буквой. Задание 2 и все задания с вводом не
перемешиваются. Проверка орфографии в полях ввода отключена. Уход со вкладки не блокируется,
но считается, и счётчик уходит учителю в поле «Время».

**Если отправка не прошла.** Ученик видит экран с текстом результата и кнопками «Copy result»
и «Try again». Скопированный текст можно прислать учителю любым способом — данные не потеряются.

## Чек-лист перед раздачей

- [ ] Прослушать `listening.mp3` и убедиться, что отрывки идут в порядке: пробка → концерт в
      Глазго → Кэти и Джейми → потоп в Йорке → реклама Restful Eyes.
- [ ] Пройти тест целиком с ключом — в форму должно прийти `70 / 70 (100%) — оценка 5`.
- [ ] Пройти с двумя-тремя намеренными ошибками — проверить, что отчёт называет верные ответы.
- [ ] Перезагрузить страницу в середине теста — ответы, попытки прослушивания и таймер должны
      восстановиться.
- [ ] Пройти до конца, перезагрузить — должен появиться экран «You have already taken this test»;
      затем `?teacher=reset` должен вернуть титульный экран.
- [ ] Проверить, что ответ реально появился в таблице формы, и что поля «По заданиям», «Ошибки»
      и «Writing» пришли целиком, а не обрезанными.
- [ ] Открыть на телефоне: пропуски в заданиях 4, 6, 7 не должны ломать чтение текста.
- [ ] Убедиться, что балл нигде не показывается ученику.
